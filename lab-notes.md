# SOC Cyber Security Lab Notes

## Lab Overview
This document contains notes from my Cyber Security Home Lab where I practiced SOC monitoring, attack simulation, and incident detection.

The lab environment was created to simulate real-world cyber attacks and analyze them using security monitoring tools.

---

## Lab Environment

Virtualization Platform:
- VirtualBox

Machines Used:
- Kali Linux (Attacker Machine)
- Windows 10 (Target Machine)
- SOC Monitoring System

Security Tools:
- Splunk (SIEM)
- Wazuh (Endpoint Security Monitoring)
- Nmap
- Wireshark
- Metasploit

---

## Lab Network Architecture

Kali Linux (Attacker) → Internal Network → Windows Machine (Victim)

All machines are connected in the same internal network to simulate a real attack scenario.

---

## Commands Used in Lab

### Check IP Address

ipconfig

ifconfig


### Test Connectivity

ping <target-ip>


### Network Scanning

nmap -sV <target-ip>


### Detect Open Ports

nmap -p- <target-ip>

## Activities Performed

### 1. Lab Setup
- Installed virtualization software.
- Created virtual machines.
- Configured internal network.
- Verified connectivity between systems.

### 2. Attack Simulation
- Performed network scanning from attacker machine.
- Identified open ports and services.
- Simulated login attempts.

### 3. Log Monitoring
- Collected logs from Windows system.
- Observed authentication logs.
- Checked alerts generated by monitoring tools.

### 4. Traffic Analysis
- Monitored network packets.
- Identified suspicious activity.
- Investigated connection attempts.

---

## Observations
- Multiple open ports were discovered during scanning.
- Login attempts were recorded in system logs.
- Monitoring tools generated alerts during attack simulation.
- Network traffic increased during scanning activity.
