Incident Report 4 – Unauthorized Access Attempt
Incident Title

Unauthorized Access Attempt Detected

Date

(Add date)

Summary

Multiple login attempts were detected on the Windows system indicating a possible unauthorized access attempt.

Alert Source

Authentication failure logs.

Indicators

Repeated login failures

Login attempts from unknown IP

Account access attempts.

Investigation Steps

Reviewed authentication logs.

Identified repeated login failures.

Verified source system.

Confirmed simulated attack.

Risk Assessment

This type of attack can lead to:

Account compromise

Data breach

Privilege escalation.

Recommended Security Measures

Enable account lockout policy

Implement multi-factor authentication

Monitor login attempts continuously

Block suspicious IPs.

Conclusion

Attack was successfully detected and analyzed within the SOC lab environment.
